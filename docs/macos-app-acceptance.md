# macOSオーバーレイ受け入れテスト

この文書は、CIでは再現できないmacOSのフルスクリーン、Spaces、Stage Manager、ディスプレイ構成変更を実機確認するためのチェックリストです。最終PR前の手動ゲートとして実施し、結果欄へOS・アプリのバージョンと結果を記録します。

## 前提

1. macOSアプリを起動する
2. 認証なしのComet環境へ接続してRoomを選択する
3. 設定画面の「コメントとスタンプをテスト表示」で通常デスクトップ上に表示されることを確認する
4. 背後のアプリをクリック、ドラッグ、キー操作できることを確認する

## フルスクリーン表示

各アプリでスライドショーをフルスクリーン表示し、別端末またはWebアプリからコメントとスタンプを送ります。

| 対象                   | 確認内容                                                               | OS・アプリバージョン | 結果   | 備考 |
| ---------------------- | ---------------------------------------------------------------------- | -------------------- | ------ | ---- |
| Keynote                | オーバーレイがスライドより前面に表示され、ページ送りを妨げない         | 未実施               | 未実施 |      |
| Chrome / Google Slides | オーバーレイがスライドショーより前面に表示され、ページ送りを妨げない   | 未実施               | 未実施 |      |
| PowerPoint             | オーバーレイがスライドショーより前面に表示され、発表者ツールを妨げない | 未実施               | 未実施 |      |

確認項目:

- コメント、組み込み絵文字スタンプ、カスタム画像スタンプが表示される
- マウスとキーボード操作がスライドアプリへ届く
- アプリ切り替え後もオーバーレイが不要にフォーカスを奪わない
- メニューバーから「表示を緊急停止」すると即座に消える
- 再度表示を有効にすると新しいイベントから表示が再開する

## SpacesとStage Manager

| 操作                      | 期待結果                                       | 結果   | 備考 |
| ------------------------- | ---------------------------------------------- | ------ | ---- |
| 通常Space間を移動         | 選択したディスプレイの各Spaceで表示される      | 未実施 |      |
| フルスクリーンSpaceへ移動 | スライドより前面に表示される                   | 未実施 |      |
| Stage Managerを有効化     | 背後のウィンドウ操作を妨げず表示される         | 未実施 |      |
| Mission Controlを開く     | オーバーレイが操作対象ウィンドウとして現れない | 未実施 |      |

## 複数ディスプレイ

| 操作                           | 期待結果                               | 結果   | 備考 |
| ------------------------------ | -------------------------------------- | ------ | ---- |
| 「すべてのディスプレイ」を選択 | 全画面へ同じイベントが表示される       | 未実施 |      |
| 個別ディスプレイを選択         | 選択画面だけへ表示される               | 未実施 |      |
| 選択画面の解像度を変更         | 新しい画面サイズへウィンドウが追従する | 未実施 |      |
| 選択画面を取り外す             | メイン画面へ一時的にフォールバックする | 未実施 |      |
| 同じ画面を再接続する           | 永続UUIDにより元の選択画面へ復帰する   | 未実施 |      |
| ミラーリングを開始・終了       | 表示が重複せず、画面構成へ追従する     | 未実施 |      |

## 既知の制約

- macOSの保護されたシステム画面、ログイン画面、スクリーンセーバーより前面への表示は対象外です。
- アプリ独自の排他的表示方式や将来のmacOS変更により、通常のフルスクリーンSpaceとは異なる挙動になる可能性があります。
- CIはwindow level、Spaces用collection behavior、クリック透過と表示先選択ロジックを検証しますが、対象3アプリでの実表示は実機テストが必要です。
